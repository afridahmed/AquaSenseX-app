## 🌊 What Is AquaSense X?

<table>
<tr>
<td width="50%">

AquaSense X is a **complete IoT water intelligence system** built for hikers, campers, and travellers who drink from unknown sources every day.

It combines a **sensor-embedded smart bottle** with a **cloud-connected web app**, **Gemini AI coaching**, and a **crowdsourced community water map** — giving you real-time, data-driven answers to the question nobody else has solved:

<br/>

> **"Is this water actually safe to drink?"**

<br/>

The answer is on your phone. In 5 seconds. From anywhere in the world.

</div>

<table>
<tr>
<td align="center" width="50%">

**⚗️ Isolated Water Analysis Chamber**

The core innovation. A micro-valve draws 5ml of water into an isolated chamber, analyses it with the full sensor suite, then discards it. The sensors **never touch** your drinking water.

</td>

UV-C LED in the cap auto-cycles every 4 hours. Manual trigger, night mode, and travel mode available from the app. Completely isolated from the sensor module.

```

╠══════════════════════════════════════════════════════════╣
```

## 📡 Sensor Suite

<br/>

<div align="center">

| Sensor | Module | Parameter | Unit | GPIO |
|:---:|:---:|:---:|:---:|:---:|
| Turbidity | SEN0189 | Water clarity | NTU | 34 |
| TDS | Capacitive | Dissolved minerals | ppm | 35 |
| Temperature | DS18B20 | Water temp | °C | 32 |
| pH | DFRobot pH V2 | Acidity | pH | 36 |
| Water Level | Capacitive strip | Volume | ml | 33 |
| Motion | MPU-6050 | Drinking detection | — | I2C |

</div>

<br/>

> 💡 **ADC1 pins only (GPIO32–39)** — prevents WiFi/BLE interference on ESP32-S3
>
> ⚡ **Power:** Two AMS1117-3.3 LDOs + MT3608 boost converter + decoupling caps at every sensor

## 🗄️ Firestore Schema

```
📁 sensorReadings/latest    ← ESP32 writes here every 5s
      temp, turbidity, tds, ph
      waterLevel, battery, qualityScore, timestamp

📁 users/{uid}              ← Profile + settings
      name, email, bottleId, dailyGoalMl, fcmToken
      settings/darkMode: boolean
      settings/notifications: { 6 toggles }

📁 readings/{id}            ← Manual recorded readings
      userId, all sensor values, qualityScore, timestamp

📁 communityReports/{id}    ← Community map pins
      sourceName, sensor values
      qualityScore, verifiedByCount, posX, posY, timestamp

📁 bottles/{bottleId}       ← Device registry
      ownerId, battery, firmwareVersion, lastSeen
```

## 🚀 Getting Started

<br/>

### Prerequisites

```bash
# Node.js — nodejs.org (LTS version)
node --version

# Firebase CLI
npm install -g firebase-tools
firebase login
```

<br/>

### Firebase Setup

Enable these in [Firebase Console](https://console.firebase.google.com):

```
✅ Authentication     → Email/Password + Google
✅ Firestore          → Test mode
✅ Hosting            → Get started
✅ Cloud Messaging    → Default enabled
✅ Cloud Functions    → Blaze plan
```

<br/>

### Environment Variables

Create `.env` in project root:

```env
REACT_APP_FIREBASE_API_KEY=your_key
REACT_APP_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
REACT_APP_FIREBASE_PROJECT_ID=your_project_id
REACT_APP_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
REACT_APP_FIREBASE_APP_ID=your_app_id
REACT_APP_GEMINI_API_KEY=your_gemini_key
```

<br/>

### Deploy

```bash
firebase deploy
# Live at https://aquasense-x.web.app
```

<br/>

### Flash ESP32

```cpp
// aquasense.ino — set these values
const char* WIFI_SSID           = "YOUR_WIFI";
const char* WIFI_PASSWORD       = "YOUR_PASSWORD";
const char* FIREBASE_PROJECT_ID = "YOUR_PROJECT_ID";
const char* FIREBASE_API_KEY    = "YOUR_API_KEY";

// Board: ESP32S3 Dev Module
// Upload Speed: 921600
// Baud: 115200
```

<br/>

### Get Android APK

```
1. pwabuilder.com
2. Enter: https://aqua-sense-x-app.vercel.app
3. Build → Android → Download APK
4. Install directly on phone (no Play Store)
```

<br/>

### Get iOS IPA

```
1. pwabuilder.com → iOS → Download IPA
2. Install via AltStore (altstore.io)
3. No App Store needed
```
